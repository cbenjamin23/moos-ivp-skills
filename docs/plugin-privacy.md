# Privacy policy

Last updated: September 17, 2026.

MOOS-IvP Skills is a package of instructions, reference material, templates, and
local helper scripts for coding agents. It does not operate an account service,
host a plugin backend, or include author-operated telemetry.

When you use a skill, your coding agent may read or change files in the
workspace you give it, including source code, mission configuration, and MOOS
logs. It may run local tools to build or test that work. Some workflows also
consult public MOOS-IvP documentation, clone public source repositories, or
fetch map data when those actions are needed and permitted by the agent's host.
The plugin does not automatically send your workspace files or logs to the
plugin author.

The agent platform may process your prompts, files, tool results, and generated
output under that platform's own settings and privacy terms. This notice does
not govern the platform or public services the agent accesses. Review a command
or upload before approving it if your workspace contains sensitive data.

If you choose to [open a GitHub issue](https://github.com/cbenjamin23/moos-ivp-skills/issues),
the information you post there is handled by GitHub and may be public. Remove
private paths, credentials, logs, or other sensitive content before posting.

For privacy questions about this plugin, use the repository's
[Issues page](https://github.com/cbenjamin23/moos-ivp-skills/issues).
